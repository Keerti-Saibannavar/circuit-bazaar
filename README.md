# circuit-bazaar
CircuitBazaar 🔌

A simple electronics components storefront built with plain HTML, CSS, and JavaScript. Browse microcontrollers, sensors, and tools & accessories — every "Add to Cart" button links directly to a matching Amazon search so you can compare prices and buy from a trusted seller.
🔗 Live site:https://keerti-saibannavar.github.io/circuit-bazaar/
Features
📦 Product catalog organized by category (Microcontrollers, Sensors, Tools & Accessories)
🔍 Live search — filter products as you type
🏷️ Category filter buttons
🛒 "Add to Cart" buttons that open Amazon search results in a new tab
